# Run settings guide

There are several different Ironmon rulesets, and they do not all allow the same things. This page is a practical starting point for choosing patcher settings. The rules for the event, Discord or streamer you are playing with always take priority.

The score log is not a gameplay change. It can be enabled for any run, but its points use the Ironmon VS scoring system. Only compare scores between runs using the same rules.

## Settings key

- **Legal by default:** normally safe for that ruleset.
- **Ruleset-dependent:** only legal when that specific ruleset or event says so.
- **Not legal by default:** leave it off unless you are playing a modified or private version of the rules.

| Patcher option | What it changes |
| --- | --- |
| **Classic** | Original Gen 3 physical/special categories and ability effects. |
| **Modern** | Physical/special split and updated effects for existing Gen 3 abilities. |
| **Lab start** | Starts the game in Oak's lab and changes early resources/progression. |
| **Rival level** | Changes the opening rival battle and its experience. |
| **No HM friend needed** | Lets the main Pokémon use field HMs without carrying a separate HM friend. |
| **Lit Rock Tunnel** | Removes the need to use Flash to see in Rock Tunnel. |
| **Move relearner** | Adds an extra move-relearning option using a TM. |
| **Friendship controls** | Changes friendship, affecting moves such as Return and Frustration. |
| **Poison-friendly forest nurse** | Adds healing access that is not normally available while poisoned. |
| **Early encounter rotation** | Changes early encounter availability. |
| **Hidden items** | Changes how hidden items appear or refresh. |
| **Move information** | Adds extra battle information, including move descriptions and categories. |
| **Automatic score log** | Records milestones using the Ironmon VS scoring system. It does not enforce rules. |
| **Randomiser settings** | Changes Pokémon, moves, trainers, items, levels or other seed details depending on the selected randomiser options. |

## Standard Ironmon

Use the normal Standard Ironmon randomiser settings and rules.

**Normally legal:**

- **Classic** mode.
- The automatic score log, for personal tracking.
- The normal randomiser settings for Standard Ironmon.
- The ordinary game map, progression, healing and HM-friend rules.

**Normally not legal unless the rules say otherwise:**

- **Modern** mode.
- Lab start.
- Custom rival levels.
- No HM friend needed.
- The Move relearner.
- Friendship controls.
- Early encounter rotation.
- Hidden-item changes.
- Extra healing access.
- Extra move information.

**Usually cosmetic or convenience-only, but still disclose them:**

- Lit Rock Tunnel.
- The Baconmon title screen.
- The Nuz-guide, if it is only being used as a rules reference.

If a tournament or community provides a specific randomiser preset, use that preset rather than trying to reproduce it manually.

## Ultimate Ironmon

Ultimate is stricter than Standard Ironmon and has additional restrictions around moves, items and party usage.

Use the same conservative setup as Standard Ironmon:

- Classic mode.
- Standard Ultimate randomiser settings.
- No Baconmon gameplay changes unless the Ultimate rules explicitly allow them.
- Score log only for tracking, with the same scoring caveat above.

Modern, Lab start, custom rival levels, No HM friend needed, extra healing, the Move relearner, friendship controls, encounter rotation, hidden items and extra information should all be treated as **not legal by default**.

## Kaizo Ironmon

Kaizo adds the one-Pokémon challenge and stricter healing, move and item rules.

**Safe starting point:**

- Classic mode.
- The official Kaizo randomiser settings.
- The normal Kaizo starter, pivot, healing, item, move and HM-friend rules.
- Score log enabled only as a tracker.

**Not legal by default:**

- Modern mode.
- Lab start or extra starting resources.
- Custom rival levels.
- No HM friend needed.
- Extra healing or the poison-friendly nurse.
- Move relearner.
- Friendship controls.
- Early encounter rotation or changed hidden items.
- Move information beyond what the rules already permit.

Lit Rock Tunnel may be a convenience, but it changes the normal Flash requirement and should be disclosed and approved before using it.

## Survival Ironmon

Survival has its own allowances and restrictions. Some things that are illegal in Kaizo are deliberately legal in Survival, but that does not make every Baconmon option legal.

**Use:**

- The official Survival randomiser settings.
- Classic mode unless the current Survival rules explicitly allow Modern.
- The normal Survival rules for healing, held items, moves, HMs and trainer battles.
- Score log for tracking, with the same scoring caveat.

**Still rules-dependent or not legal by default:**

- No HM friend needed.
- Lab start.
- Custom rival levels.
- Move relearner.
- Friendship controls.
- Encounter rotation.
- Hidden-item changes.
- Poison-friendly forest nurse.
- Extra move information.

Do not use the Survival allowances as a reason to enable unrelated Baconmon features. They are specific exceptions to the Survival rules.

## Ironmon VS-style run

Ironmon VS-style runs may use the VS scoring system, but the legal gameplay settings still come from the specific rules being followed.

**Normally legal:**

- The automatic score log.
- Classic mode, unless the event says it is using Modern.
- The official VS randomiser settings.
- Any quality-of-life feature explicitly included in that VS ruleset.

**Rules-dependent:**

- Modern mode.
- Encounter rotation.
- Lab start.
- Custom rival level.
- Move information.
- Hidden items.
- Healing changes.
- No HM friend needed.
- The Move relearner.

The score log is designed to record VS-style milestones automatically, but it does not prove that a run followed the rules.

## Ironmon Journey, Survival Revival and other named variants

Named variants are not interchangeable. Journey, Survival Revival, challenge-server presets and streamer-specific rules can each permit different features.

For these runs:

1. Find the current rules for that exact variant.
2. Start from the closest conservative profile above.
3. Turn on only the features explicitly allowed by that ruleset.
4. Record the patcher settings and randomiser settings with the run.

If the rules do not mention a Baconmon feature, treat it as **not legal until confirmed**. This is especially important for Modern mechanics, No HM friend needed, extra healing, encounter changes, hidden items and information aids.

## Nuzlocke, custom and casual runs

These are not bound to the Ironmon rules unless you choose to use them.

You can legally choose:

- Classic or Modern at the start of the run.
- The automatic score log.
- Lab start and a custom rival level.
- No HM friend needed.
- Lit Rock Tunnel.
- The Move relearner.
- Friendship controls.
- Encounter rotation and hidden-item changes.
- Extra move information.
- Any randomiser settings you agree to use.

Write down the settings and win conditions before starting if you want the run to be reproducible.

## My optional Baconmon ruleset

The full Baconmon rules are my own take, inspired by Kaizo Ironmon and Ironmon VS. They are optional; you do not need to use them to use the patcher.

I am especially interested in feedback on the rules themselves, including unclear wording, edge cases and loopholes. Please report anything reproducible with the settings and steps needed to see it.

## Important notes

- The patcher does not enforce every rule.
- Start a fresh run when changing the setup.
- Read the patcher's output log. Conflicting changes can be skipped.
- Keep modified runs separate from standard Ironmon results unless the rules explicitly allow the changes.
- If a community rule and this guide disagree, follow the current community rule and let me know so I can correct the guide.
