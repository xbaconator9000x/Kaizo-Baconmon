# Run settings guide

Kaizo Baconmon is modular because different runs want different things. There is no single correct patcher setup. Pick the profile closest to the run you are actually playing, then agree on any changes before comparing results with someone else.

## Standard Baconmon / my full setup

Use this when you want the full Kaizo Baconmon experience:

- Leave **Core Baconmon Package** selected.
- At the start of the run, choose **Classic** or **Modern**.
- Keep the **automatic score log** enabled. It uses the Ironmon VS scoring system.
- Choose the randomiser settings that match the challenge rules.
- Read the in-game Nuz-guide for the full Baconmon rules.

The Core package is the convenient starting point, but it is still made up of selectable features. Untick anything you do not want to use.

## Classic run

Choose **Classic** at the start of the run when you want the original Gen 3 physical/special categories and original ability effects.

This does not undo other changes. Lab start, rival level, HM changes, encounter changes, move information and other selected options still apply.

## Modern run

Choose **Modern** at the start of the run when you want the physical/special split and updated effects for existing abilities.

Modern changes battle outcomes, so treat it as its own run type when comparing scores or results.

## Ironmon VS-style run

Use only the features allowed by the ruleset or group you are following. The automatic score log is intended to make this easier: it records milestones using the Ironmon VS scoring system, so you can track progress or chase a personal best instead of only counting a Champion win.

Do not assume that every Baconmon feature is legal in an Ironmon or Ironmon VS run. In particular, check rules around Modern mechanics, field HMs, information aids, encounter changes, hidden items and healing.

## Nuzlocke, custom or casual run

Pick the features that make the run more fun or more convenient. The patcher is meant to support these runs too. You can use Classic or Modern, keep or remove the score log, and select only the quality-of-life changes you actually want.

If you are making your own rules, write down the settings and win conditions before starting so the run is reproducible.

## My optional ruleset

The full Baconmon rules are my own take, inspired by Kaizo Ironmon and Ironmon VS. They are optional; you do not need to use them to use the patcher.

I am especially interested in feedback on the rules themselves, including unclear wording, edge cases and loopholes. Please report anything reproducible with the settings and steps needed to see it.

## A few important notes

- The patcher does not enforce every rule. The score log records progress; it does not certify that a run is legal.
- Start a fresh run when changing the setup.
- Read the patcher's output log. Conflicting changes can be skipped.
- Keep modified runs separate from standard Ironmon results unless the rules explicitly allow the changes.
