Batch randomiser · beta

Choose a fresh, unrandomised US FireRed 1.1 ROM above. The randomiser applies your selected patches first, then makes new seeds. Choose 1–100 ROMs per batch. Larger batches download in ZIP parts of up to 10 ROMs. Download each part before continuing. Seeds, settings and patch notes are included; spoiler logs are kept separate for after the run.

Runs in your browser with UPR-ZX 4.6.0. You’ll need internet to load its Java runtime the first time. This is a beta; the desktop reports don’t cover Android performance or actual 100-ROM batches.

Ironmon presets use UTDZac’s published FireRed settings. Encounters only is a simple Nuzlocke option: wild species change; trainer teams, learnsets and stats stay as supplied. Patch features above are independent of the preset.
Settings string

Use Custom to paste a compatible 321-format FireRed settings string. Keep the same engine, settings, base ROM and seed to reproduce a batch.

Randomizer: UPR-ZX by Ajarmar, based on Dabomstew’s randomizer (GPLv3). Presets: UTDZac and contributors. Browser Java runtime: CheerpJ by Leaning Technologies.
