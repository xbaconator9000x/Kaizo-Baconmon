# Put Baconmon on GitHub

1. Sign in as xbaconator9000x and create a public repository called Kaizo-Baconmon. Tick Add README so it starts with a main branch.
2. Upload the contents of the Kaizo-Baconmon folder from the ZIP. Keep index.html at the top level. If uploading from your phone doesn't keep the folders, use a computer or let the connected GitHub integration upload them.
3. In Settings → Pages, choose Deploy from a branch, then main and /(root). Save.
4. Wait for GitHub to finish publishing. The patcher should then be at https://xbaconator9000x.github.io/Kaizo-Baconmon/ .
5. Once everything is ready, send Maple this repository link: https://github.com/xbaconator9000x/Kaizo-Baconmon .

GitHub's instructions:
- https://docs.github.com/en/repositories/creating-and-managing-repositories/creating-a-new-repository
- https://docs.github.com/en/pages/getting-started-with-github-pages/configuring-a-publishing-source-for-your-github-pages-site
